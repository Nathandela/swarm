2. Full-width session board

Drag the width. The name and path expand first; the summary gets the remaining room. Fixed semantic fields stay stable, and every row is clamped before it can wrap.

Proposed behavior: fixed fields keep their readable maximums. The existing 120-column layout remains the baseline: 20 cells for name, 24 for path, and 40 for summary. Above that, 55% of every extra cell goes to the discussion name and 45% to the path; below it, the summary contracts first, then name and path.
