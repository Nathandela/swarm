# Building the Rust implementation

The first implementation decision is the owner of each effect. Rust can prevent using a moved file descriptor twice inside one process. It cannot prevent two processes from delivering the same Discord message, two controllers from writing the same PTY, or a delayed task from acting on a replacement worker. Preserve the process boundaries and express those distributed constraints in the protocol, store and tests. [System invariants](../../invariants/system-invariants.md)

## Workspace and dependency direction

Start the migration with a workspace at the repository root and one production package under `crates/swarm`. Use a separate black-box driver that only knows executable paths, OS interactions and fixture formats. It can remain a script until the driver actually needs a compiled implementation. Build both against the same pinned fixtures. Move the new workspace into the foreground only after the install rehearsal. Keep the two Go references reproducible from immutable Git revisions after retiring their source from the Rust release tree.

| Initial Rust module | Public operation or output | Allowed dependencies |
|---|---|---|
| `entry`, `cli`, `board` | Parse args, choose role, produce terminal cells, dispatch user intent | Local client, terminal platform support, projections. Board modules consume snapshots and events. |
| `ipc` | Frame decoder/encoder, negotiated roles and typed requests | Byte IO and data codecs. Model application decisions outside this module. |
| `supervisor`, `session` | Instance ownership, per-session command ordering, transitions and reconciliation | IPC, provider operations, runtime records, shim client, platform identity. |
| `shim`, `terminal` | Own PTY, process group, VT grid, transcript and current attach generation | IPC, OS descriptors, VT parser and bounded sinks. Enforce a compile boundary here if imports from application orchestration appear. |
| `providers/{claude,codex,agy,hermes,opencode}` | Report evidence-backed capabilities as a function of version, role and runtime mode; execute the supported operations | Narrow session operations, native transports, hook and OS observations. Keep provider-private error/status decoding within its module. |
| `discussion`, `schedule`, `discord` | Worker and manager transitions, scheduled claims, Discord transport and publications | Shared session operations behind a local client or the owning service entry. Connector-only dependencies terminate at Discord. |
| `store`, `platform` | Safe file replacement, exact file identity, private paths, PTY and process primitives | Standard library and reviewed OS bindings. Per-store schema and recovery decisions live beside the owning domain. |

Prefer private modules, explicit constructors and a finite provider enum while there are five installed provider drivers. Introduce a trait at a boundary where the caller genuinely needs substitutable implementations, such as an owned PTY stream used in a real kernel test and a scripted recording. Use exhaustive matching for lifecycle transitions. Distinguish a session ID, instance ID, native conversation ID, operation ID and attach generation with lightweight typed values. Validate them once at ingress. Store references to immutable identity in a durable intent before crossing a process boundary.

For example, the receiver of a native decision validates the current session, instance, native request ID and inspected content hash; the decision writer checks those facts again immediately before the external effect. A stale decision remains diagnosable even if a newer request has identical display text. A Rust type certifies the parsed shapes; the live check certifies authority at that instant. [Native command surface](https://github.com/Nathandela/swarm/blob/f26648d69086e329132ac7849954d2f29a895387/cmd/swarm/native_requests.go)

## Concurrency contracts

| Owner | Execution model and boundedness | Shutdown and failure proof |
|---|---|---|
| Board | One input/update/render loop. A coalescing projection stream carries latest state. Raw attach releases terminal ownership and gets its own byte path. | Restore modes and focus on every normal/error return. Kill a client inside attach and verify a second client can acquire a lease. |
| IPC connection | One stateful reader and one ordered writer per connection. Keep partial frame bytes and offset owned by that connection. Validate maximum declared length before allocating. | If an interrupted operation loses its byte offset, close the stream. Reusing it can turn a suffix into a new header. Test pauses at every byte split, cancelled writes and truncated EOF. |
| Shim | Keep PTY draining independent of slow storage, subscriber socket writes and controller availability. Serialize grid updates and snapshot/live boundaries. For lease-sensitive writes carry generation through the final PTY write gate. | Revoke input authority before releasing the old connection. A late cleanup for generation A must leave B intact. Signal only after validating process birth identity. Reap only children the shim owns. |
| Supervisor | Keep session state exclusive to the transition owner. Offload blocking filesystem, native probes and process waits from any shared event loop. Bound concurrent probes and explicitly limit their lifetimes. | Stop admission, drain or persist accepted work, cancel timed waits, join owned background tasks, release lock and socket in ownership order. Exiting a daemon preserves independent shims. |
| Scheduler/Discord | Process at most one owner-authorized effect for one operation. Keep journalled intent, current audience/instance and effect status visible during restart. Handle provider waits outside the state lock. | A caller timeout can drop its interest in a result while the side effect completes. Retry using the operation ID and durable proof. On ambiguous outcomes, return uncertainty and reconcile. |
| Media | Bound each call and speaker buffer by time and bytes. Associate every frame and playback result with a call generation. Scope the helper to its parent and private pipes. | Revoke media forwarding and clear queued playback before waiting for external providers. Ignore delayed packets from the expired generation. |

There is no requirement to make every path asynchronous. Compare a dedicated blocking PTY read loop against readiness-driven IO under the real attachment workload. The winning design must drain through supervisor loss, sustain burst output, restore input modes, meet the measured latency target and cease consuming CPU when idle. The choice depends on the number of threads, subscriber backlog and time spent waiting measured on both operating systems. A single runtime for the network-facing connector can coexist with a blocking shim. Keep a bounded blocking pool only where a measured caller can exhaust shared execution capacity.

Use owned descriptors and scoped cleanup. Restrict unsafe process, terminal and signal operations to small reviewed platform modules; record each precondition including descriptor ownership and which thread or child may use it. Treat a process group, foreground terminal state, signal disposition and a controlling terminal as separate resources. Verify session leadership, inherited descriptors, termios, suspend/exit and resource release with a real PTY. [Shim survival and signal cases](https://github.com/Nathandela/swarm/tree/f26648d69086e329132ac7849954d2f29a895387/internal/shim) · [Terminal handoff cases](https://github.com/Nathandela/swarm/tree/f26648d69086e329132ac7849954d2f29a895387/internal/attach)

## Compatibility at the byte and store boundaries

* Feed Go-generated valid, truncated and oversize frames to Rust and the converse. G1 declares a four-byte big-endian length including the type byte, capped at 1 MiB, followed by control, output, input or snapshot payload. Clean EOF at a boundary and partial EOF differ. Pin the zero first byte assumption used by the shared socket classifier. Continue treating PTY bytes as bytes across all layers. [Frame implementation](https://github.com/Nathandela/swarm/blob/f26648d69086e329132ac7849954d2f29a895387/internal/wire/wire.go)
* Encode wire types and file versions explicitly. Use checked conversion for lengths, sequence numbers and native identifiers. Compare absent, explicit null, zero, empty list and unknown fields against each existing reader. An extension tolerated on the wire can still disappear during a read-modify-write cycle. Hash the exact published representation where receipts require it. Compare existing fixtures containing non-ASCII text, escapes, empty fields and ordered attachment hashes before choosing a Rust serializer configuration. [Shim codec tests](https://github.com/Nathandela/swarm/blob/f26648d69086e329132ac7849954d2f29a895387/internal/shimwire/shimwire_test.go) · [Discord delivery contracts](discord.md)
* Test Rust reading existing metadata, writing a permitted mutation, and Go reopening **and mutating** the result. Reopen from Rust again and check all safety-relevant fields, active obligations and paths. Unknown safety-critical schemas block writes before state changes. Use exclusive same-directory temporary files and atomic replacement with the existing permissions. The Go metadata writer documents process-crash durability. A stronger power-loss guarantee requires its own filesystem-level test and latency budget. [Metadata writer](https://github.com/Nathandela/swarm/blob/f26648d69086e329132ac7849954d2f29a895387/internal/persist/persist.go) · [Cutover](transition.md)
* Preserve native paths as OS paths through acquisition and validation. Keep the specified wire encoding at the boundary. Reject an unrepresentable path explicitly instead of silently replacing bytes in an ownership key. Test symlinked and physically distinct roots, path changes after validation and rollback with the original endpoint identity. [Checkout ownership](https://github.com/Nathandela/swarm/blob/f26648d69086e329132ac7849954d2f29a895387/docs/ops/checkout-inventory.md)

## Spike decisions

Run each candidate against the same corpus and record the dependency graph, licenses, supported install targets, compile time, artifact size and residual maintenance burden. Commit the winning configuration with its lockfile and toolchain. Delete discarded implementations after recording the decision and retaining their shared test corpus.

| Decision | First experiment | Reject or revisit when |
|---|---|---|
| Dashboard renderer | Prototype the board with Ratatui, compare its cell buffer and a real terminal screen with the pinned Go output. Include narrow, wide and resized forms, styles, focus, mouse coordinates and Unicode width. | A matched cell-buffer test still diverges in a real emulator, or layout cannot match without a parallel renderer. Evaluate direct cell rendering through a terminal backend using the same input/output fixtures. [Ratatui test backend](https://docs.rs/ratatui/latest/ratatui/backend/struct.TestBackend.html) |
| VT engine | Replay the existing raw stream, query replies, alternate-screen modes, horizontal clipping, mouse modes, chunk boundaries and snapshot sanitation against candidate maintained Rust terminal emulators. | Any missing query reply causes a waiting native CLI, an escape survives the protected snapshot, a subscriber stalls draining, or memory depends on lifetime output. A parser that only yields escape tokens still needs a grid engine. [VT corpus](https://github.com/Nathandela/swarm/tree/f26648d69086e329132ac7849954d2f29a895387/internal/vt) · [Reply contracts](https://github.com/Nathandela/swarm/blob/f26648d69086e329132ac7849954d2f29a895387/internal/vt/replies_test.go) |
| PTY interface | Try a safe Unix PTY binding against a real CLI, process-group escalation, native shared-owner Hermes, resize, signals and saved termios. Compare with a narrow platform implementation only where a required operation is unavailable. | The library hides ownership needed to establish a controlling terminal, misattributes child completion, leaks descriptors after restart or fails macOS/Linux containment. |
| Discord network and media | Keep SDK types at the connector boundary. Characterize Gateway resume, nonce recovery, REST rate limits, participant changes and encrypted audio with the pinned call helper. Compare a Rust media candidate independently. | Unsupported DAVE rekey, stale consent or poor onset/stop latency rejects a media candidate. A text gateway library passing JSON fixtures cannot close the real encrypted media gate. [Call qualification](discord.md) |

## Local quality and debugging

Pin the toolchain, commit Cargo.lock, run formatting, warnings-as-errors lint for supported targets/features, workspace tests with the locked graph, and release-mode builds. Keep diagnostics readable with component, operation, instance/generation, state before/after, effect result and monotonic elapsed time. Use a private opt-in event trace and redact command text, credentials, messages and PCM. Limit cardinality and bytes. Map a user-facing error class and exit status at the CLI boundary; retain source chains for local debugging. Intent/commit/receipt spans let a maintainer distinguish a lost acknowledgement from a second external effect.

The first CI-free build ticket must provide a single documented local gate returning nonzero on any failed required case or unexecuted requested target. Exercise individual binaries at their normal entry points in addition to module-level tests. A deterministic unit model can enumerate lease takeover, cancellation and crash schedules; the independent differential driver must still run them against real processes. Profile optimized binaries, report instrumented runs separately, and compare CPU, memory, allocations and input latency with equivalent Go results under the same workload. Remove a proposed optimization when evidence shows its bookkeeping exceeds the work saved. [Measurement protocol](qualification.md)
