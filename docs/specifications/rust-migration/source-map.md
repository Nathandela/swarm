## Hidden crossings to break deliberately

- The shim, daemon, persistence and upgrade code all import the managed-login package. Preserve the safety information each reader consumes by giving the corresponding invariant to its owner. For example, receipt of a historic input embargo cannot be interpreted as permission to type. Retain an explicit blocked state and surface unsupported import identities. [Shim native process](../../../internal/shim/native_process.go), [manager login](../../../internal/daemon/manager_login.go), [compatibility manifest](../../../internal/upgrade/manifest.go), [persistence](../../../internal/persist/persist.go)
- The top-level client protocol imports the remote pairing implementation. The owner protocol still carries shared native decisions, message content hashes and launch identities. Specify these locally, test both sides of the old negotiated connection, and delete the pairing capability from the candidate. The submit-framing rule also serves ordinary CLI sends. [Pairing coupling](../../../internal/protocol/pairing.go), [shared schemas](../../../internal/protocol/schema), [submit framing](../../../internal/submitframe/submitframe.go)
- The durable idempotency store and journal originate in remote-era architecture. Native operations and owner launches depend on them, and the manifest must preserve their durable results. Reimplement only the retained effects, key conflicts and history readers. [Owner launch](../../../internal/daemon/owner_launch.go), [OpenCode receipts](../../../internal/skeleton/opencode_receipt.go), [CLI pilot](../../../cmd/swarm/pilot.go)
- The calls branch adds production code under [services/discord-voice](https://github.com/Nathandela/swarm/tree/da7b9f2dfa7e2c6960bd860a72459c0448845c82/services/discord-voice) and touches shared adapters, protocol, manager, speech, packaging and scripts. Keep its opt-in helper contract until a Rust replacement passes the encrypted call suite. Ensure a clean base install does not acquire the optional media runtime. [Call integration](discord.md)

## Reproduce the coverage check

Run from the repository root. This detects any missing or duplicate inventory entry for the pinned main tree. Repeat against a prospective pin during scope review; a match on directory names still requires reading the changed *files*. Use the call-branch diff separately to review behavioral changes inside existing owners.

```python
from collections import Counter
from pathlib import Path
import re
import subprocess

sha = "f26648d69086e329132ac7849954d2f29a895387"
paths = subprocess.check_output(["git", "ls-tree", "-r", "--name-only", sha], text=True).splitlines()
detailed = {"cmd", "internal", "deploy", "services", "scripts", "packaging"}
expected = {"/".join(p.split("/")[:2]) if p.split("/")[0] in detailed
            else p.split("/")[0] for p in paths}
chapter = Path("docs/specifications/rust-migration/source-map.md").read_text()
rows = [line.split("|")[1] for line in chapter.splitlines() if line.startswith("| `")]
actual = Counter(name for row in rows for name in re.findall(r"`([^`]+)`", row))
assert set(actual) == expected, (expected - set(actual), set(actual) - expected)
assert all(n == 1 for n in actual.values()), actual
```

On a clean detached reference checkout, `git ls-files` produces the tracked input paths for the same comparison. The immutable tree command above also works after candidate files land on the migration branch. Inspect the supplemental source using `git diff --name-status 22f3090d...da7b9f2d`.
