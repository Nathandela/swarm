- `TestGuildAttachmentIngressUsesVisibleForwardAndReply` recreates the visible Discord forward shape. It checks an admitted direct or attachment-only request, reply-to-forward, renewed CDN authorization from the same visible message, forbidden foreign replies, exact image and document bytes, and failure status.
- `TestWorkerFilesRetainExactBytesAndScopeAfterAcknowledgement` checks immutable staged bytes, exact worker binding, conflicting retries, pinning through settlement, and bounded reclamation. The daemon regression exercises the real worker and shim proof, then deletes the original local file before readback.
- `TestTeammateFilePublicationMultipartAndScopedMention`, `TestTeammateFilePublicationResumesReceiptAfterRestart`, `TestPersonalFilePublicationReconcilesFromSameDMHistory` and `TestTeammateMentionQuestionWaitsForVerifiedReceipt` exercise exact bytes, 429 replay, authorization, restart reconciliation and one verified recipient. The sender holds an ambiguous upload or mention until Discord provides matching evidence.
