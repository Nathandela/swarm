=== Defect 3: build-darwin E1.2 assertion's allowlist regex is too narrow, not TAB-broken ===

ci.yml:191-201 (job "build-darwin", step "Assert darwin binary links only system libraries
(E1.2)") extracts each linked path with `awk '{print $1}'` and rejects anything not matching
`^/usr/lib/(libSystem|libresolv)`. Verified directly: awk's default field-splitting already
strips otool's leading TAB (confirmed via `od -c` on the awk output -- no tab byte reaches the
grep), so the failure is NOT tab-indentation corrupting the match. The real defect is that the
allowlist itself is too narrow: a plain `CGO_ENABLED=0 go build ./cmd/swarm` on darwin/arm64
still links `/System/Library/Frameworks/CoreFoundation.framework/...` and
`/System/Library/Frameworks/Security.framework/...` (Go's darwin runtime/crypto-x509 root-store
path pulls these in regardless of cgo), and neither is covered by the `/usr/lib/(...)` prefix,
so every darwin build now trips the "E1.2 violation" branch and `exit 1`.

Actual CI log (run 31837056072, job "build-darwin (darwin/arm64)"):
  	/usr/lib/libSystem.B.dylib (compatibility version 0.0.0, current version 0.0.0)
  	/System/Library/Frameworks/CoreFoundation.framework/Versions/A/CoreFoundation (compatibility version 0.0.0, current version 0.0.0)
  	/System/Library/Frameworks/Security.framework/Versions/A/Security (compatibility version 0.0.0, current version 0.0.0)
  E1.2 violation: binary links non-system dylibs:
  /System/Library/Frameworks/CoreFoundation.framework/Versions/A/CoreFoundation
  /System/Library/Frameworks/Security.framework/Versions/A/Security

Reproduced locally (same libs list, awk output confirmed tab-free via od -c):
  $ GOOS=darwin GOARCH=arm64 CGO_ENABLED=0 go build -o /tmp/swarm-darwin-arm64 ./cmd/swarm
  $ libs=$(otool -L /tmp/swarm-darwin-arm64 | tail -n +2 | awk '{print $1}')
  $ echo "$libs" | grep -vE '^/usr/lib/(libSystem|libresolv)'
  /System/Library/Frameworks/CoreFoundation.framework/Versions/A/CoreFoundation
  /System/Library/Frameworks/Security.framework/Versions/A/Security
