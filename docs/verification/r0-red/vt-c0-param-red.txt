== 1. Timing reproduction of the hang, straight through Feed (80x24) ==

Probe: feed each input to a fresh Emulator and time the single Feed call.
Floor for reference: the cheapest per-byte work this wrapper can do that still
touches the whole grid and the scrollback is one LF per byte.

    floor: 2049 LF                            2049 bytes  25.992042ms
    REP burst, no C0 (clamped, current fix)   2049 bytes  73.782083ms
    C0 splits an unmarked REP count             18 bytes  3.729837834s   <-- BLOCKER 1
      "X\x1b[" + strings.Repeat("9\x00", 7) + "b"
    C0 splits an unmarked CHT count             21 bytes  5.588531667s   <-- BLOCKER 1
      "\x1b[" + strings.Repeat("9\x00", 9) + "I"
    C0 strips the private marker, burst x64    641 bytes  2.55637725s    <-- BLOCKER 2
      "X" + strings.Repeat("\x1b[?99999\x00b", 64)
    C0 strips the private marker                11 bytes  35.19825ms     <-- BLOCKER 2
      "X\x1b[?99999\x00b"
    C0 strips the marker after an intermediate  12 bytes  30.761583ms    <-- BLOCKER 2 (variant
      "X\x1b[?99999 \x00b"                                                   not in the review)
    C0 strips the marker, 8-bit CSI             10 bytes  28.289541ms    <-- BLOCKER 2
      "X\x9b?99999\x00b"

Each additional "9\x00" pair multiplies blocker 1's cost by ten, so ~25 bytes is
minutes: the original unbounded-in-a-single-call hang, still reachable.
Blocker 2 costs 3.7ms per input byte, the same magnitude as the pre-fix numbers
(513 B -> 2.51 s, 2049 B -> 10.2 s) that identified the hang in the first place.
