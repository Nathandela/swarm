--- CORRECTION 2026-08-15 (post-review, appended; original text above unmodified) ---
Mutation 2's recorded clean FAIL predates the stopSignal mechanism and no longer holds
against the shipped code: with the outer stopped() guard deleted, the suite fails only
probabilistically (~3/30 at -race -count=30) because the inner stopSignal select is the
fail-closed gate and the outer guard is an optimisation narrowing the window. The guard is
therefore NOT deterministically pinned by that mutation. The Start()-reset fail-open the
reviewer proved (redundant Start orphaning a parked relay's stop channel) is now fixed in
Start (state-gated reset) and pinned deterministically by
TestSingleMachineAdapter_RedundantStartDoesNotOrphanTheStopSignal.
