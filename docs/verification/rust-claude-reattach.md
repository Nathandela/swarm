# External Claude Agent View reattach

`swarm reattach --cli claude` inventories native `claude agents --json` background sessions. `--dry-run` only inventories and `--all` includes settled sessions. A live source requires `--take-over`, which runs the pinned native supervisor's `claude daemon stop --any` before acquiring any session. Swarm checks the selected transcript and profile before invoking takeover. The owner independently requires an exact settled Agent View row, checkout, transcript and authority. The shim repeats the check immediately before invoking native `--resume`; native hooks confirm the original conversation identity.

Installed Claude Code 2.1.329 on Linux passed the isolated `claude_native_linux.sh <staging> <installed-claude> rust_claude_resume.py external` fixture. A real background worker got a synthetic loopback answer and remained live. Dry-run, CLI without takeover, and a direct owner request could not acquire it. Explicit takeover settled the native source, created one Swarm row for the same native conversation, and rendered its old answer without replaying the original user turn. A duplicate was refused and no fixture processes survived.

macOS Clippy passed. The native macOS background witness remains open. The protected fixture stopped an attempted creation of `/tmp/cc-daemon-501` by the installed Claude background bootstrap.
