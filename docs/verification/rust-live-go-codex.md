# Live Go Codex owner round trip

With both Go compatibility flags set, the Rust owner can adopt the pinned Go wire-v2 shim of an ordinary managed Codex terminal. It authenticates the original shim's private sockets and native TUI birth identity. It also checks the original backend record against the shim's native-writer record and verifies the original native app-server birth identity and private socket peer. A read-only app-server probe matches the persisted conversation exactly once in the loaded inventory and checks its checkout. Auxiliary native threads may share the inventory. The Rust bridge keeps terminal I/O on the original Go shim. The Go owner can subsequently start on the same state and reconnect.

The Linux x86-64 fixture used pinned Go `f26648d69086e329132ac7849954d2f29a895387` and actual Codex 0.151.0 and 0.172.0. The latter uses a per-UID mode-0700 directory with a mode-0600 listener named by the SHA-256 of the requested session socket path. A substituted alias was rejected before connecting. A single isolated network and process namespace hosted all three owners and a loopback Responses server. Each owner submitted a different terminal prompt and displayed its own reply. The fixture checked the actual kernel birth and PID of the original shim, TUI and app-server, the backend socket inode and authenticated peer, a single native rollout containing all three prompts, and refusal of a forged conversation ID before input. It restores the original Go metadata after the forged-ID probe.

Run `python3 -Bu scripts/verification/live_go_codex.py PINNED_GO RUST SCRATCH` inside a Linux sandbox with private network, PID, and temporary-directory namespaces. Stage the actual Codex executable read-only at `SCRATCH/bin/codex` and keep the scratch path short enough for Unix sockets. Pass `0.172.0` as the optional final argument for that version. Only the fixture loopback model and generated profile are used.

The signed Darwin arm64 Codex 0.172.0 witness uses `sh scripts/verification/run-macos-live-go-codex.sh /path/to/signed/codex`. It builds private copies of pinned Go and the Rust candidate that substitute deterministic session IDs only. Those IDs make it possible to precompute a finite set of exact vendor sockets and their lock files under the existing UID directory. The fixture requires those paths to be absent before it starts. Its sandbox permits each exact fixture socket and lock, the disposable profile, and the specific loopback model port. It denies access to the real home and other vendor paths. This witness does not require a second user account or changes to the installed daemon.

The Darwin vendor publishes the socket under the physical `/private/tmp` path, so Rust derives its expected target using the physical temporary directory. If the original Go shim and both native processes have stopped, Rust may read an exact dangling 0.172.0 alias. A surviving short listener blocks the stopped import. The fixture retires only its own locks and non-listening sockets.

The `9ecc2f27` rehearsal with installed Codex 0.172.0 passed on Darwin arm64 and Linux x86_64. The original Go shim, client and app-server stayed live while Rust admitted a second ordinary, non-worktree session through the same owner socket. Both conversations appeared on the roster with distinct native IDs. Export refused the new Rust session while it was running and kept the original Go identities live. After a verified Rust stop, export published the stopped successor for pinned Go. Go saw both rows and continued the Rust-created conversation through the original rollout while the first Go PTY was still alive. On Linux the final run mounted the installed provider directly at the recorded `PATH` location. An earlier symlink-based fixture saw the same native continuation and a different Go fingerprint, which includes the executable path spelling.

The witness covers attached terminal I/O and intact native state. Structured input and Context Guard remain with their original owner. Scheduled, account-managed and degraded launches, other vendor socket layouts, and live classic agy require separate qualification.
