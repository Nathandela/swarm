On the first full Go round the build, vet and lint gates passed. Five packages failed. Six individual tests failed across `cmd/swarm`, `internal/daemon` and `internal/e2e`. The `internal/skeleton` package exceeded the default ten-minute cumulative timeout and one `internal/teammatemanager` fixture supplied a macOS path alias to a canonical-path check. The checkout-inventory fixture had used the test process as its shim while inheriting the developer checkout as that process’s directory. Running it from its own fixture directory fixed the isolated reproduction. With package parallelism capped at two, 95 packages passed and eight contained no tests. Only the cumulative timeout and canonical-path fixture failure remained. The fixture now resolves its temporary directories and the full normal/race rounds use the repository’s existing 35-minute package budget. Keep the first failures in the evidence even if a less contended run passes.

A separate macOS regression exercised four handoff outcomes 100 consecutive times after an absolute-deadline socket reader replaced socket option changes after peer closure. Private handoff files are removed on a definite pre-effect refusal and retained when a worker may already have consumed the launch.

The first full cross-built Rust test round on Linux found a wide-character snapshot mismatch also observed on macOS, and a Discord test that tried to run the build host’s executable path. The fleet runs the actual Linux binaries on `tf_nathan` in private scratch without replacing the installed Swarm or using an automated runner. [Linux test runner](../../scripts/verification/rust_linux_tests.py).

Mixed-language live shim adoption, complete provider semantics, live Discord text/files/calls, 24-hour soaks, the full target matrix and installed upgrade/rollback remain release gates.
