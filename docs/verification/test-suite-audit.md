# Test suite audit

The cleanup starts at upstream main `7f67c067`. The separate nested-worktree review ends at `0100e86f` and supplied prior failures and verification evidence. Agents inspected lifecycle, providers and communications, and platform gates in parallel. Three independent reviewers then challenged the proposed removals and checked the fixture diffs. All fixture runs used disposable state. This audit did not deploy binaries or alter existing sessions or Git worktree registrations.

## Cleanup and evidence

| Finding | Decision and equivalent coverage |
| --- | --- |
| Checkout inventory hit its discovery and association deadline | The original test failed twice in a checkout sharing 196 Git registrations (21.78 s and 22.57 s) and passed five times from neutral scratch. The test now uses an independent temporary cwd and explicitly checks implicit cwd discovery. The twelve-repeat inventory suite passed. Hidden/resume lineage, live descendants, receipts, inert local state, and unchanged Git registration assertions stay. Production large-repository behavior is tracked in `agents-tracker-icxe`. |
| Adapter source fences ran the same scan under two names per package | Removed the two R7 duplicates. `TestContractPackage_NoIOInSource` and `TestStateless_NoIOInSource` retain the exact scan of every production Go file in their packages. Four originals passed five repeats. Both retained tests passed five race repeats and rejected a seeded forbidden I/O call in disposable source copies. R7 provider and backend behavior checks stay. |
| Two renderer tests asserted the same idle permission revocation | The retained daemon test waits for initial output, revokes the permission while the stream is idle, and requires the loop to exit without cancellation. The removed case never inspected its collector or tested the per-emission guarantee in its name. The remote gateway test withdraws permission after tap and before the first emission, and the separate remote watch wiring and wire compatibility cases stay. Baseline renderer and connected tests passed twelve race repetitions. |
| A natural-exit test raced to attach within a 400 ms fixture delay | The original missed child PID output twice in ten race repetitions. The separate gated fixture passed all ten. The combined test gates natural exit until the attached client has observed the actual child, verifies matching child PID before parent output in the persisted transcript, checks the original exit code/signal and completion bounds, and verifies no surviving child. It still exercises S5 containment through the real PTY. Cooperative TERM, no-PTY KILL and wire compatibility cases stay separate. |
| Permission fixtures assumed a permissive umask | Explicit chmod now establishes the intentionally unsafe/public or preserved foreign modes in daemon, diagnostic logs, Discord, voice, Darwin upgrade-log, and timer fixtures. An ambient `0077` previously masked the mode, causing failures or skipping a repair path. Recorded `0022` controls passed. Existing rejection, link custody, unchanged bytes/modes, and rollback checks stay. |
| Repeated real smoke builds added host load | The CLI role tests now reuse the existing supervised binary builder per suite invocation. Each test retains its own state and socket. CLI and e2e daemon starters report fixture logs on failed readiness, keeping their original handshake assertions and startup deadlines. The shim compatibility fixture registers process cleanup as soon as it starts the shim, before readiness can fail and delete scratch files. |
| The bounded process fixture could read an empty PID as zero | Two of four baseline Node runs hit this across the timeout and external TERM cases. A disposable 100 ms write window reproduced it. The fixture publishes the numeric PID by same-directory rename after the signal handlers are installed. Five direct runs and the widened-write-window control passed, with all ten recorded grandchild PIDs confirmed gone. Exit 124, exit 143 and exact child containment remain independently asserted. |

## Platform controls and residual issues

- The untagged Android gate, mobile, release manifest, and push gateway packages passed locally. Strict Phase B manifest and conversation-copy checks, OpenCode Python preflight, relay admission/configuration, the Firestore runner self-test and exit propagation, and the macOS Apple signing and bridge harness also passed.
- The Android report checker accepted a disposable stale report from an obsolete task with `tests="1" skipped="1"` and no Gradle invocation. Follow-up `agents-tracker-5znt` tracks fresh results and an executed-test assertion. The local AAR run was stopped during disk pressure. Android Gradle/APK/instrumentation, remote emulators, and full iOS Xcode/SDK preflight remain separate gates.
- The positive three-second version probe and negative hanging probe exercise distinct production behavior. The slow positive and a short diagnostic probe each hit the intentional five-second production limit during loaded runs. The diagnostic passed ten load-controlled repeats. The assertions and production deadline are retained.
- The first full snapshot attempt ran in the editable worktree. Go discovered removed test names before the lane edits landed and compiled their changed packages afterward. The generated test-main build errors from that run are invalid baseline results. Before/after comparisons above use targeted binaries captured before editing or disposable source controls.
- The unchanged terminal restore test failed twice in twelve repeats and seven times in eight with `GOMAXPROCS=1`. The failed cases painted the initial board but no board after restore. Bubble Tea v2.0.2 resets a shared ticker that the old renderer goroutine can still stop. A temporary module replacement that gave each renderer a separate ticker passed all eight one-thread repeats. [Bubble Tea v2.1.2](https://github.com/charmbracelet/bubbletea/blob/v2.1.2/tea.go#L1519-L1536) first shipped that fix. `agents-tracker-ipoo` tracks the runtime fix and dependency qualification. The regression test still exercises the production handoff API.
- The four CLI smoke cases had six startup failures in twelve baseline executions. The shared-binary candidate had one in twelve. That first failure preceded both the socket and the fixture daemon log. Unattended restart also hit its cold readiness deadline during the branch-wide translated x86 run, then passed in the full combined native arm64 CLI suite. The x86 compatibility control hit its original PID-file deadlines but no longer left late shims reading deleted config. Follow-up `agents-tracker-8te8` tracks startup timing. `agents-tracker-homd` tracks suite-level custody for shim fixture failures.

The combined release follow-up is `agents-tracker-2qb2`. The dispatcher owns publication after the combined candidate passes its release gates. The patch version is one above the latest published stable version at release time.
