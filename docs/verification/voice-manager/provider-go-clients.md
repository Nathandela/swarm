2026-11-08 — direct Go Gradium provider client slice

Implemented in internal/voice/gradium using existing github.com/coder/websocket v1.8.13. No dependency or module changes. This is the provider transport boundary within P6; it does not complete P6, acoustic qualification, native phone audio, controller utterance admission or publication.

API: Config{Region,Language,Voice,Format}; OpenSTT/OpenTTS wait for authenticated setup→ready. Session exposes Ready, Events, Done, Err, SendAudio, Flush, SendPhrase, End and Close. Key is supplied in memory and used only in X-Api-Key. Production destinations are fixed auto/EU/US official hosts; redirects are refused. No public endpoint override, reconnect or input replay exists. Formats are explicit mono PCM16 rates 8000/16000/24000/44100/48000; default is pcm_24000. STT configured input rate remains separate from reported internal sample_rate; TTS OutputFormat reflects reported output rate.

Wire/lifecycle bounds: setup/dial/ready 10s; each write 5s or earlier caller cancellation; inbound JSON 128KiB; audio 64KiB with even byte count; phrase input 4096 UTF-8 bytes; event queue16. One reader goroutine and synchronous serialized writers; Close cancels transport and waits for reader exit. Slow consumers fail explicitly with backpressure, close the socket, and invalidate queued output. Consumers still fence already-received frames by their media generation. EOF without native EOS is failure; malformed, unsupported, uncorrelated and oversized events fail closed. Typed errors retain only categories and numeric HTTP/provider codes, never response text, credentials, headers or raw transport error strings.

STT accepts one utterance per connection. One positive flush ID may be pending; audio/text effects are not replayed; SendAudio during flush returns ErrFlushPending. Matching flushed seals the input and any following transcript/end_text is marked Late. A new utterance opens a new connection. Stream IDs, start/stop times, step indices/durations and VAD horizon/probability pairs are preserved. TTS receives whole caller phrases; optional model flushing appends the documented <flush> tag. Actual deployed TTS returns an uncorrelated flushed frame with no flush_id, and additional audio follows before EOS; this is not spoken completion or STT finality. The provider tests retain that shape explicitly.

The independent overlay /private/tmp/gradium-review-s7adqb7i/overlay.json reproduced three concrete failures before edits: Close left completed-stream audio buffered; a lone UTF-16 surrogate became an accepted replacement character; and an inline <flush> tag was dispatched then caused an unmatched TTS acknowledgement failure. The original writer-cause finding was timing-sensitive, so the strengthened permanent regression and the independent overlay were repeated after the causal fix. No actual credential disclosure was observed; characterization logging was tightened proactively as requested.

Close now cancels and explicitly closes transport before waiting for Done, then synchronously drains the closed Events channel for both failed and successful streams. A completed native EOS retains Err()==nil. Already-received events still require the caller's media-generation fence.

The existing standalone UTF-16 escape scanner moved from voicewire into internal/jsontext.ValidateUnicode. This helper validates UTF-8 and surrogate pairing only, with generic errors containing no input fragments. It imposes no schema, key-case or duplicate-key rules. Both provider decode and voicewire call it before Go's JSON decoder can replace malformed text. Wire's existing application validation remains in place. Tests reject lone high/low halves and wrong pairs while preserving valid supplementary pairs, literal escaped backslashes and valid UTF-8; the existing full wire suite also passes.

SendPhrase rejects the reserved literal <flush> in caller text before any write, with or without its flush flag. The flag owns insertion of exactly one model-control tag. The documented actual TTS zero-ID model-flushed event remains distinct from STT's correlated flush and from playback completion.

A blocked write retains its active, internally timeout-bounded context under the state lock. If its socket reader observes a transport failure first, fail snapshots an already-expired active write's causal timeout, retains one terminal category, and immediately cancels and CloseNow's transport. The reader never waits for the writer lock/gate. The writer returns the retained terminal cause. An adversarial actual loopback fixture establishes a stalled context.Background writer, triggers server TCP half-close and concurrent Close, and verifies Close and the writer both finish within one shared one-second shutdown budget. It also asserts the active background write has an internal deadline no more than five seconds away. A pre-effect cancellation check also prevents an already-cancelled operation from winning the writer semaphore race and dispatching input.

The opt-in characterization fixture now emits only recognized event names and whitelisted numeric public metadata. Provider text, error messages, headers, arbitrary fields, request identifiers, audio payloads and codec tokens are not logged. Error fixtures containing a synthetic sentinel key verify both direct terminal errors and diagnostic sanitization, including an unknown event name.
